Panduan Import Tamu

Untuk menambahkan banyak tamu sekaligus, kamu bisa mengunggah file berformat .CSV.

Aturan Susunan Kolom:
  • Kolom A: Nama Tamu / Pasangan (Wajib)
  • Kolom B: Nomor WhatsApp (Opsional)
Contoh Tampilan di Excel:
Kolom A (Nama) Kolom B (WhatsApp)
Rifa & R 081234567890
Kiki & Pasangan 085712345678
Upil & Dirga (Boleh kosong)
Cara Simpan dari Excel:
  1. Buka Excel / Google Sheets.
  2. Isi data nama & nomor WhatsApp sesuai kolom.
  3. Pilih menu File > Save As / Download.
  4. Pilih format CSV (Comma delimited) (*.csv).
